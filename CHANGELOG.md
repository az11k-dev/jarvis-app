# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

---

## [Unreleased]

### Added

- Hands-free mode: wake word «Джарвис» / "Jarvis", automatic end-of-speech detection, replies only to phrases that start with the wake word, tap-to-interrupt
- On-device voice activity detection over the raw microphone stream (adaptive noise floor, pre-roll)
- OpenAI Responses API with function calling and built-in web search, replacing text-command parsing
- Neural JARVIS voice (OpenAI TTS) with sentence-by-sentence playback and device-voice fallback
- Arc-reactor HUD with conversation transcript; voice and mic settings persist between launches
- `open_url` action; reminders are read aloud by JARVIS when they fire
- Vision: `analyze_image` tool — JARVIS opens an in-app scanner (`expo-camera`) that shoots by itself after focusing — back or selfie camera — or picks from the gallery, sends the photo to a vision model and reports what it sees, reads or translates text (`EXPO_PUBLIC_OPENAI_VISION_MODEL` overrides the model)
- Background listening on Android: a microphone foreground service (local module `modules/jarvis-background`) keeps the wake word working with the app in the background or the screen off, with a «Выключить» action in its notification

### Fixed

- Returning to the app in the middle of a turn (e.g. from the camera) reset JARVIS to standby while it was still thinking
- Repository names with dashes were mangled (markdown stripping removed `-`)
- Selected voice was overwritten on every reply

### Changed

- Speech recognition now uses OpenAI `gpt-transcribe` (`EXPO_PUBLIC_OPENAI_TRANSCRIBE_MODEL` overrides it) for better accuracy; the on-device recognizer is the offline fallback when OpenAI is unreachable or takes longer than 8 s
- Conversation mode: after an answer JARVIS keeps listening for 10 s (15 s if it asked a question) without the wake word; speaking keeps the conversation going, silence, a sign-off («отбой», «спасибо, всё») or opening another app returns it to standby
- Upgraded Expo SDK 54 → 58 (React Native 0.88, React 19.3) and all Expo modules
- Splash screen is now configured via the `expo-splash-screen` config plugin
- Switched to Continuous Native Generation: `android/` and `ios/` are generated by `expo prebuild` and no longer committed
- Updated deprecated APIs (`expo-image-picker` media types, `expo-audio` permissions)
- Fixed React Compiler lint errors (refs read during render)

### Removed

- GitHub voice commands (create or delete a repository, read recent commits) and the `EXPO_PUBLIC_GITHUB_TOKEN_KEY` setting; no GitHub token is bundled into the app anymore
- Unused dependencies: `openai`, `axios`, `expo-av`, `expo-camera`, `expo-file-system`, `expo-status-bar`, `react-native-tts`, `@react-native-voice/voice`, `react-native-background-actions`, `react-native-markdown-display`, `@react-native-community/cli`
- Obsolete config: `newArchEnabled`, `edgeToEdgeEnabled` (now always on), manual `appComponentFactory` manifest override

## [1.0.0] - 2025-07-16

### Added

- 🗣️ Voice Input (STT: Speech to Text)  
  Users can now speak directly with J.A.R.V.I.S.

- 🤖 GPT-4 Powered Responses  
  Smart conversational replies generated by OpenAI

- 🧠 Contextual Memory (AsyncStorage)  
  J.A.R.V.I.S. remembers key actions and recent input during a session

- 🚀 App Launching via Voice  
  Opens apps like Telegram, YouTube, etc., based on spoken commands

- 🧠 Smart Commands via OpenAI (Search & Generation)
  - "Find a guitar lesson on YouTube" → opens relevant YouTube search
  - "Create a login page in React" → generates React login page code
